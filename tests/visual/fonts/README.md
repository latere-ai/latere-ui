# Reference fonts

IBM Plex Sans (variable 400–600) and IBM Plex Mono (400) are copied unchanged from `origo-web/internal/web/assets/`. Their SIL Open Font License is in [IBMPlex-OFL.txt](IBMPlex-OFL.txt). These assets are fixture-only and are not published with the package.

Inter, Instrument Serif and JetBrains Mono are pinned `@fontsource` development dependencies. Consumers provide their own fonts; the shared presets do not fetch fonts.
